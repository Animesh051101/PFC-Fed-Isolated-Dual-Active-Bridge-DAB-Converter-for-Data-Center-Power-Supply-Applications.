# PFC-Fed Isolated Dual Active Bridge (DAB) Converter for Data Center Power Supply Applications 
 Developed and simulated a 400 V to 48 V, 1 kW isolated DAB converter integrated with a single-phase
boost PFC front end.
Implemented Single-Phase-Shift (SPS) control and analyzed DC-link and output-voltage regulation under steady-
state and varying operating conditions.
